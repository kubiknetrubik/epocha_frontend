# Эпоха - фронтенд (ЛР-5)

SPA для просмотра исторических словарей архаизмов с датировкой вхождения слов в язык.
Интерфейс гостя: **лента** и **плитка**. Данные берутся только из mock-коллекции.

Стек: React 19, TypeScript, Vite, React Router, React-Bootstrap.
Бэкенд (NestJS): https://github.com/kubiknetrubik/epocha

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

## Страницы

### Нижняя панель навигации (на всех страницах)

| Пункт | Иконка | Действие | Доступность |
|---|---|---|---|
| Лента | домик | переход на `/feed` | доступен |
| Добавление | плюс | переход на страницу добавления словаря | недоступен  |
| Плитка | сетка | переход на `/catalog` | доступен |
| Вход | стрелка в дверь, справа | переход на страницу входа | недоступен  |

Активный пункт выделяется увеличенной иконкой, недоступные - полупрозрачные.

### Лента - `/feed`, `/feed/:id`

Одна карточка словаря поверх автоматически проигрываемого видео
(с `id` - выбранный словарь; `/feed` без `id` сам открывает самый свежий словарь `/feed/:id`,
потому что запрос ленты без `id` на бэкенде возвращает 400).

Поля:
- **видео** на весь экран; если `videoUrl` пустой или файл недоступен - видео по умолчанию;
- **название** словаря;
- **краткое описание** - по умолчанию 2 строки;
- **количество лайков**;
- **даты** - нижняя и верхняя граница периода вхождения слов в язык.

Кнопки:
- **сердце** - лайк (для гостя только счётчик, ставить лайк можно после входа, ЛР-6);
- **стрелка вниз «Следующий»** - следующий словарь, по кругу (`/feed/:nextId`);
- **шеврон** - развернуть / свернуть описание (больше / меньше).

### Плитка - `/catalog`

Список опубликованных словарей в 2 столбца. Удалённые словари не показываются.

Поля:
- **дата «нижняя граница»** - фильтр: показываются словари, у которых начало периода не раньше указанной даты;
- карточка словаря: **изображение** (если `imageUrl` пустой или недоступен - изображение по умолчанию), **название**, **количество лайков**, **нижняя граница** периода.

Кнопки:
- **«Искать»** - применить фильтр; значение сохраняется в адресе (`/catalog?startDate=1700-01-01`) и не сбрасывается после поиска и при возврате из ленты;
- **нажатие на карточку** - переход в ленту, начиная с этого словаря (`/feed/:id`).
